# APEX HYBRID

Mobile-first Hybrid Strength & Nutrition web app (Apple Fitness dark aesthetic + FitnessFAQs Hybrid PPL + MacroLens nutrition).

## Deploy to GitHub Pages
1. Create a new repository on GitHub (e.g., `apex-hybrid`).
2. Upload `index.html`, `.nojekyll`, and `README.md` to the root of the `main` branch.
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, select **`main`** and **`/ (root)`**, and click **Save**.
4. Open the published `https://<username>.github.io/apex-hybrid/` URL in **Safari** on your iPhone and tap **Share → Add to Home Screen**.
