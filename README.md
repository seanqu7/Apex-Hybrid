# APEX HYBRID

Mobile-first Hybrid Strength & Nutrition web app (Apple Fitness dark aesthetic + FitnessFAQs Hybrid PPL + MacroLens nutrition).

## Files Included
- `index.html` — Complete self-contained app
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` — iPhone Home Screen & PWA app icons
- `manifest.json` — Standalone Home Screen web app manifest
- `.nojekyll` — Clean GitHub Pages static serving
